# Test Data

Static fixtures (YAML files, directories) used by integration and system tests.

## Files / Directories

| File / Directory | Responsibility |
|------------------|----------------|
| `build_time/` | Fixtures for build-time code generation tests (valid/, invalid/, multi/) |
| `dynamic.yaml` | Sample dynamic command definitions fixture |
| `external.yaml` | Sample external command definitions fixture |
| `utils.yaml` | Utility command definitions fixture |
